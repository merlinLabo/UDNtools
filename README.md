# UDNtools

A toolset that lets UDN run standalone on PC without AVS2 components.

- **`config`**: WinForms GUI for configuring the setup, including hardware simulation, DLL patches, screen settings and keyboard bindings.
<img width="342" height="440" alt="image" src="https://github.com/user-attachments/assets/d52b9115-f8ba-42e4-ba6e-4dfbee8e07c2" />

- **`launcher`**: Native executables that actually set the environment and run, including a minimal Unity player host shell.

## Quick Start
- Install .NET Framework 4.8 runtime
- Copy `config.exe`, `launcher.exe` into the `gamedir`;
- Rename `unityhost.exe` to `DANCEaROUND.exe` and place into `%gamedir%\game`;
- Then run config.exe once to apply the patches, and click the Launch button (or launcher.exe directly) to start the game.

## UDNconfig
On startup, `config.exe` looks for a game's root directory (a folder containing `game\` and `prop\`, starting from its own directory and walking up) and loads its current configuration. **Root Dir**
field and **Browse…** button let you point it at a different backup.
- Runtime — environment variables read by the game (CONNECT_DUMMY_BI2A, STANDALONE_ENABLE, etc., written to udntools.ini) and the list of managed-DLL patches (see below).
- Audio — SET_FRONT_VOLUME / SET_WOOFER_VOLUME.
- Display — screen mode, resolution, refresh rate, V-Sync, target FPS, and the virtual-screen toggle.
- Keys — rebinds keyboard keys for the action maps embedded in Unity InputSystem action asset.

| Category | Examples |
|---|---|
| Required | standalone mode, skip seckey check, skip update check, force region, force local EA3 status, force offline entry, remove eacoin call |
| Recommended | keyboard input, force guest ending |
| Optional | unitylog, skip player calibration, unlock all songs, auto play, Testmode fix, Free Play |

## UDNlauncher
Placed in the game's root directory. On startup it will:
- Reads ``udntools.ini`` generated by UDNconfig;
- Runs an environment check;
- Sets the process environment variables the game reads (CONNECT_DUMMY_BI2A, STANDALONE_ENABLE, etc.).
- Builds the command line for game\DANCEaROUND.exe

### Launcher Command Line
``launcher.exe [args passed through to the game...]`` 
- --nowait (return immediately after launching instead of waiting)
- --check (only run the environment check, print the result, and exit — used for scripting).
